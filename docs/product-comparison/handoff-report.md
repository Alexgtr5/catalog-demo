## Что сделано

| Слой | Изменение |
|---|---|
| `entities/comparison` | Список выбранных id в Context + `useState`, синхронизация с `sessionStorage`, чистые функции `toggleComparison` / `buildComparisonRows` / `comparisonStorage` |
| `features/toggle-comparison` | Кнопка-переключатель в слоте `footer` карточки товара, уведомление о лимите |
| `widgets/comparison` | Таблица сравнения: характеристики построчно, товары по столбцам, залипающая колонка названий, удаление товара из таблицы |
| `shared/ui/ToastProvider` | Подавление дубликатов уведомлений |
| `pages/catalog` | `useProducts` поднят на страницу, данные передаются пропсами в каталог и виджет |

Покрыты все пять состояний из `spec.md`: загрузка (скелетон), пусто (`EmptyState`
«Добавьте ещё товары для сравнения»), успех (таблица), ошибка (виджет не
рендерится — каталог уже показывает ошибку с повтором), частичные данные
(неизвестные id отбрасываются при рендере, из хранилища не стираются).

## Открытые вопросы для аналитика / тимлида

Все критичные вопросы закрыты постановщиком до реализации. Остаются некритичные,
по которым приняты умолчания — их стоит подтвердить или изменить:

1. **Порядок товаров в столбцах** — сейчас по времени добавления.
2. **Кнопка «очистить всё сравнение»** одним действием — не реализована, в
   постановке не упомянута.
3. **Расположение виджета** — сейчас над сеткой товаров; альтернатива —
   закреплённая панель.
4. **Подсветка различий** между товарами — не реализована.
5. **Поведение на узких экранах** — горизонтальная прокрутка столбцов при
   зафиксированной колонке характеристик.
6. **Молчание виджета при ошибке загрузки каталога** — зафиксировано как
   предположение (`spec.md`), подлежит подтверждению, если дизайн потребует
   отдельного сообщения.
