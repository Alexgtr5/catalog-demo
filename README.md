# Каталог товаров

Демо-приложение каталога электроники на React + TypeScript + Vite.
Служит основой для прогона пайплайна фронтенд-разработки на Claude Code skills.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Дев-сервер на http://localhost:5173 |
| `npm run build` | Проверка типов и продакшн-сборка в `dist/` |
| `npm run preview` | Локальный просмотр собранного приложения |
| `npm run typecheck` | Только проверка типов |
| `npm run lint` | oxlint |
| `npm test` | Тесты (vitest + testing-library) |

## Структура

Проект следует Feature-Sliced Design:

```
src/
├── app/                       точка сборки приложения и провайдеры
├── pages/catalog/             страница каталога
├── widgets/catalog/           виджет сетки товаров и её состояния
├── features/filter-products/  фильтрация по категории и поиск
├── entities/product/          модель товара, загрузка данных, карточка
└── shared/                    UI-kit, дизайн-токены, утилиты
```

Правило импортов — слой обращается только к слоям ниже себя.

## Данные

Товары берутся из мока `src/entities/product/api/productsMock.ts` с искусственной
задержкой 700 мс — это позволяет видеть состояние загрузки.
Наборы характеристик у товаров намеренно разные: у части товаров есть поля,
которых нет у других.

Состояние ошибки проверяется без правок кода — добавьте `?fail=1` к адресу страницы.
